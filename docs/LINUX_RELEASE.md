# FountainPen Manager – Linux Portable

## Deutsch

Der GitHub-Release enthält `FountainPenManager-v<VERSION>-portable-linux.zip`, `latest.json` und `SHA256SUMS.txt`.

Nach dem Entpacken:

```bash
chmod +x start-linux.sh FountainPenManager
./start-linux.sh
```

Der Starter setzt `FPM_DATA_DIR` auf den lokalen Ordner `data/`. Datenbank, Einstellungen und Backups bleiben dadurch portabel. `FountainPenManager` und `_internal/` müssen zusammenbleiben.
